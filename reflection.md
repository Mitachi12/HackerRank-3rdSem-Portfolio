# Reflection

Working on these HackerRank problems helped me improve my understanding of basic programming and problem-solving concepts in C.

The problems covered arrays, strings, comparisons, dynamic memory allocation, and data structures. I also got practice in understanding how different approaches affect the time and space required by a program.

Solving the problems on HackerRank was useful because the code had to pass different test cases rather than just working for one example. This helped me pay more attention to input handling and edge cases.

I also learned how to organize my solutions into separate folders and maintain them in a GitHub repository. Using C for the problems gave me more practice with memory allocation and pointers, especially in problems such as Dynamic Array and Sparse Arrays.

Overall, this activity improved my confidence in solving basic algorithmic problems and helped me understand the importance of writing organized and efficient code.
